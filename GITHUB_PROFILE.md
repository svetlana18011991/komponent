# Компоненты Действий 🎓

**Интерактивное методическое пособие для школьников 4–6 классов по нахождению компонентов математических действий**

---

## 🎯 Что это?

Полноценное веб-приложение, которое помогает ученикам освоить:
- ➕ Сложение
- ➖ Вычитание
- ✖️ Умножение
- ➗ Деление

**Без установки, без зависимостей, полностью бесплатно!**

## 🚀 Быстрый старт

1. **Откройте прямо сейчас**: Перейдите в `index.html` и откройте в браузере
2. **Используйте онлайн**: Раздельте это репозиторий и активируйте GitHub Pages
3. **Для класса**: Поделитесь ссылкой на GitHub Pages с учениками

## ✨ Особенности

✅ **Интерактивные задания** — выпадающие списки, текстовые поля, проверка ответов  
✅ **Акварельный дизайн** — красиво, эстетично, не скучно  
✅ **Для всех экранов** — работает на ПК, планшете, телефоне  
✅ **Статистика** — отслеживание правильных ответов  
✅ **Бесплатно & Open Source** — MIT License  

## 📚 Содержание

1. **Памятка** — справка со всеми правилами
2. **Распознавание** — интерактивные задания на выбор
3. **Простые уравнения** — отработка базовых навыков
4. **Средний уровень** — уравнения с двумя действиями
5. **Сложные уравнения** — для продвинутых
