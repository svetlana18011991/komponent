## 🎯 О проекте

Это интерактивное методическое пособие помогает учащимся **4–6 классов** освоить навыки нахождения неизвестных компонентов в математических действиях:

- ➕ **Сложение** (слагаемые, сумма)
- ➖ **Вычитание** (уменьшаемое, вычитаемое, разность)
- ✖️ **Умножение** (множители, произведение)
- ➗ **Деление** (делимое, делитель, частное)

## ✨ Особенности

### 🎨 Дизайн
- **Акварельный стиль** — мягкие цвета, современный эстетичный вид
- **Отзывчивый дизайн** — работает на всех устройствах (ПК, планшет, телефон)
- **Интерактивные элементы** — плавные переходы, анимации, обратная связь

### 📖 Образовательный контент
1. **Памятка** — красиво оформленная справка по всем правилам
2. **Распознавание** — интерактивные задания с выпадающими списками
3. **Простые уравнения** — отработка базовых навыков
4. **Средний уровень** — уравнения с несколькими действиями
5. **Сложные уравнения** — для самых продвинутых ребят

### 🎮 Интерактивность
- ✓ **Проверка ответов в реальном времени**
- ✓ **Визуальная обратная связь** (зелёный/красный)
- ✓ **Конфетти анимация** при правильном ответе
- ✓ **Отслеживание статистики** — количество решённых задач
- ✓ **Кнопка "Начать заново"** для повторного прохождения

## 🎓 Содержание уроков

### Раздел 1: Памятка 📚
Справочник со всеми правилами нахождения компонентов:

| Операция | Найти... | Формула |
|----------|----------|---------|
| **a + b = c** | Первое слагаемое (a) | a = c − b |
| | Второе слагаемое (b) | b = c − a |
| | Сумму (c) | c = a + b |
| **a − b = c** | Уменьшаемое (a) | a = c + b |
| | Вычитаемое (b) | b = a − c |
| | Разность (c) | c = a − b |
| **a × b = c** | Первый множитель (a) | a = c ÷ b |
| | Второй множитель (b) | b = c ÷ a |
| | Произведение (c) | c = a × b |
| **a ÷ b = c** | Делимое (a) | a = c × b |
| | Делитель (b) | b = a ÷ c |
| | Частное (c) | c = a ÷ b |

### Раздел 2: Распознавание 🎯
6 интерактивных заданий на выбор правильного ответа из списка:
- Что такое 12 в выражении 12 + 8 = 20?
- Что такое 15 в выражении 15 − 6 = 9?
- И ещё 4 задания...

### Раздел 3: Простые уравнения 📖
6 базовых уравнений:
- x + 15 = 42
- x − 8 = 19
- 35 − x = 12
- x × 6 = 48
- x ÷ 5 = 9
- 56 ÷ x = 8

### Раздел 4: Средний уровень 🚀
6 уравнений с двумя действиями:
- (x + 3) × 4 = 28
- (x − 2) × 5 = 35
- x ÷ 3 + 5 = 13
- И ещё 3...

### Раздел 5: Сложные уравнения ⭐
4 уравнения с тремя действиями для самых смелых:
- (x + 5) × 2 − 4 = 16
- (x − 3) ÷ 2 + 7 = 12
- x × 4 − 8 + 2 = 18
- 72 ÷ (x + 2) = 8

## 🛠 Как изменить задания

### Добавить новое простое уравнение

1. Откройте `index.html`
2. Найдите блок `.equations-grid` в разделе "Простые уравнения"
3. Скопируйте карточку:

```html
<div class="equation-card">
    <div class="equation-type">Сложение</div>
    <div class="equation-problem">x + 15 = 42</div>
    <div class="equation-hint">💡 Подсказка: x = 42 − 15</div>
    <input type="number" class="equation-input" placeholder="Введи ответ" data-answer="27">
    <button class="check-btn">Проверить</button>
    <div class="equation-feedback"></div>
</div>
```

4. Измените `equation-problem`, `equation-hint` и `data-answer`

### Изменить цвета

1. Откройте `styles.css`
2. Найдите `:root` в начале файла
3. Измените цвета:

```css
:root {
    --color-primary: #6B8CAE;      /* Синий */
    --color-accent: #D8A5C4;       /* Розовый */
    --color-success: #A8D5BA;      /* Зелёный */
    /* и так далее */
}
```

## 📊 Функциональность отслеживания

Система автоматически считает:
- **Всего решено** — количество попыток
- **Правильных** — зелёные ✓
- **Неправильных** — красные ✗
- **Процент** — доля правильных ответов

Результаты обновляются в реальном времени!

## 🐛 Известные ограничения

- Система не сохраняет результаты (используйте скриншоты)
- Нет синхронизации между устройствами
- Уравнения не генерируются случайно
